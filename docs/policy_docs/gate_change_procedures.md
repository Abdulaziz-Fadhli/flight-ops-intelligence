# Gate Change Procedures

## When a Gate Change Is Required

Gate changes are recorded with status GATE_CHANGE and must include the new
gate number. A gate change can be triggered by aircraft swaps, a previous
flight overrunning its gate occupancy, or airport-directed reassignment
during congestion.

## Minimum Notice Requirements

- Gate changes issued more than 60 minutes before scheduled departure
  require a passenger announcement and an update to airport display boards
  only.
- Gate changes issued within 60 minutes of scheduled departure additionally
  require gate agents to physically redirect passengers already queued at
  the old gate, not just rely on announcements.
- Gate changes issued within 15 minutes of scheduled departure require a
  named gate agent to remain at the old gate for at least 20 minutes to
  redirect any late-arriving passengers.

## Connecting Passenger Handling

When a gate change affects a flight with connecting passengers arriving
from another inbound flight, operations must recalculate minimum connection
time from the new gate, not the original one. If the recalculated
connection time falls below the airport's published minimum connection
time, affected passengers must be flagged for rebooking review under the
Rebooking Policy rather than assumed to make the connection.

## Multiple Gate Changes

A flight should not be issued more than two gate changes within a single
boarding cycle. If a third change becomes necessary, the duty operations
manager must approve it explicitly and the flight should be reviewed for
a possible delay classification instead, since repeated gate changes
usually indicate a deeper ground-operations problem.
