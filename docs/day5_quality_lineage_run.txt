=== A real limitation found while testing the FAIL path ===
Pointing the gate at a nonexistent LAKEHOUSE_ROOT path caused the `deltalake`
(delta-rs) binding to panic at the Rust layer rather than raise a normal
catchable Python exception - `pyo3_runtime.PanicException` does not subclass
`Exception`, so it was not caught by the lineage_run() context manager's
`except Exception` clause and no FAIL event was emitted for that specific
case. The quality-gate business-rule failure path (shown above) raises a
normal ValueError and is correctly caught, logged, and propagated - this is
noted here rather than hidden, since it's a genuine edge case in the current
implementation rather than a fabricated success story.
