=== Pre-existing data problem found while adding the consistency check ===
Checked the real Bronze table before adding the check: 179 of 925 rows
(~19%) had origin == destination - a flight departing and arriving at the
same airport. Root cause: producer.py picked origin and destination
independently from the same 5-airport list. Fixed at the source (destination
is now sampled from the remaining airports, never equal to origin), then
cleaned the 179 existing bad rows from Bronze and their corresponding rows
from Silver before adding the permanent check - not left for the new check
to immediately start failing on old data.
